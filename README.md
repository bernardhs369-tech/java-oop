# Java OOP
 
Exercises I'm solving while learning Object-Oriented Programming in Java. Each exercise lives in its own folder and can be run on its own.
 
## Exercises
 
| Folder | Main class | What it practices |
|---|---|---|
| `person/` | `PersonDemo` | Private attributes, constructor, getters/setters, `if/else`, input validation |
| `product/` | `ProductDemo` | Constructor, methods with parameters, validation, changing object state |
| `bank-account/` | `BankAccountDemo` | Private attributes, constructor, methods with business rules (`deposit`, `withdraw`), validation |
 
## How to run
 
1. Open the project in IntelliJ IDEA (or any Java IDE).
2. Open the main class of the exercise you want (see the table above).
3. Click the green run button next to the `main` method.
Or from the terminal, inside an exercise folder:
 
```bash
javac *.java
java PersonDemo
```
 
(Replace `PersonDemo` with the main class of the exercise.)
 
## Concepts covered
 
- Encapsulation (private attributes with getters and setters)
- Constructors
- Methods with and without parameters
- Input validation with `if` and exceptions
